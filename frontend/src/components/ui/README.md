# Directory: `frontend/src/components/ui`

Located in [`frontend/src/components/ui/`](file:///c:/Users/harma/OneDrive/Desktop/veracity-maps/frontend/src/components/ui)

This directory contains reusable, accessible UI component primitives built with TailwindCSS, `@base-ui/react`, and `class-variance-authority`.

---

## Files in Directory

- **`button.jsx`**: Polymorphic button component with size (`default`, `sm`, `lg`, `icon`) and style variants (`default`, `destructive`, `outline`, `secondary`, `ghost`, `link`).
- **`alert-dialog.jsx`**: Accessible modal alert dialog for confirming destructive operations (such as session termination or dataset deletion).
- **`input.jsx`**: Styled form text input component with focus rings and disabled states.
- **`separator.jsx`**: Horizontal or vertical visual divider.
- **`sheet.jsx`**: Slide-out drawer panel (used for inspection drawers and layer controls).
- **`sidebar.jsx`**: Collapsible application sidebar container, trigger buttons, and navigation groups.
- **`skeleton.jsx`**: Animated loading placeholder for asynchronous data fetches.
- **`tooltip.jsx`**: Hover tooltip component for icon controls and map toolbars.
- **`attachment.jsx`**: File attachment card preview.
